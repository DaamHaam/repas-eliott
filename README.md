# Eliott, 18 ans — Tous à table !

Formulaire familial pour le repas auberge espagnole du 31 octobre 2026. Une réponse indique le prénom, le nombre de convives et les contributions choisies parmi 18 places. Tableau public en direct ; liens personnels de modification ; résultats et export CSV pour les organisateurs.

Application dans `repas-eliott/` : `npm ci`, puis `npm run dev`. Backend : `npm run backend`. Vérification : `npm test` et `npm run build`.

La configuration de production ne contient que l’URL publique Convex. Les clés privées et les données des participants ne sont jamais versionnées.

Point à décider plus tard : ouvrir ou non des contributions supplémentaires au-delà des places prévues.
